# Academy

The Academy teaches research judgement and operation. Docs explain the product.

Planned learning areas are foundations, research, evaluation, portfolio, operations, and advanced use. Their curriculum is owned by [spec 07 §4](../docs/specs/07-open-source-project-organisation-spec.md#4-documentation-and-academy).

Each lesson should use an available example pack, make its assumptions clear, and ask the learner to inspect evidence. Add runnable exercises with the corresponding implementation checkpoint. Do not teach a favourable backtest as proof of an edge.
