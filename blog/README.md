# Blog

Publish project changes, research/evaluation, engineering/trust, and case studies. Store full lifecycle case studies under `blog/case-studies` when evidence exists.

Posts link to the canonical specification, example pack, or approved result. They do not redefine product behaviour. Distinguish design intent from implementation and operating evidence.

No case study or performance result is included in this bootstrap. Publication rules are in [spec 07](../docs/specs/07-open-source-project-organisation-spec.md).
